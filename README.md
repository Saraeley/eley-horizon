# ELEY Horizon

A geospatial freeze-readiness console for ELEY watering equipment, customized from [God’s Eye View](https://github.com/bilawalsidhu/gods-eye-view).

Open **index.html** directly in your browser. Internet access is required for CDN libraries and satellite tiles; no npm installation or build is needed for this ELEY profile.

The current profile uses fictional customers and illustrative freeze contours. Alert dispatch prepares a local draft; it sends no messages.

See [ELEY-HORIZON.md](ELEY-HORIZON.md) for capabilities, settings, shared-agent usage and the roadmap. The original application documentation is preserved in [README.upstream.md](README.upstream.md).
